Pathways in Tech

Tech has something for everyone! Whether you're interested in designing video games or creating the next ChatGPT, there are endless pathways. The five main areas are:

  • Software Engineering - building the apps, websites, and games people use
  • Artificial Intelligence & Data - turning data into insights and intelligent systems
  • Infrastructure & Systems - running, scaling, and securing the platforms behind the software
  • Design & Product - shaping how products look, feel, and solve user problems
  • Emerging Technology - developing cutting-edge tech that defines the future

These areas work together to give us an end product. Design shapes the experience, software engineering builds the product, AI and data add intelligence, infrastructure keeps everything running reliably, and emerging technologies push the boundaries of what’s possible.


But because tech careers are so diverse, it can be hard to know where to start. To make this easier, we've created a table that helps you discover which of the five main areas might interest you based on your subject preferences.NOTE: all tech career pathways value innovation, collaboration and problem solving.

Software Engineering

Careers focused on designing, building, and maintaining software systems for web, mobile, and games.

Frontend Development

Build interactive user interfaces for the web

×

Frontend Development

Description: Frontend developers build the user-facing part of websites and applications, ensuring they are visually appealing, interactive, and responsive across devices.

Recommended Education: Bachelor’s in Computer Science, Web Development Bootcamps, or self-taught with portfolio.

Key Skills:

  • HTML/CSS/JavaScript
  • React/Vue/Angular
  • TypeScript
  • Responsive Design
  • Accessibility
  • Performance

Common Roles: Frontend Engineer, UI Developer, Web Developer.

Good For: Creatives who enjoy coding visual experiences and building user interfaces that people interact with.

Step by Step Frontend Development Roadmap

Backend Development

Build the server-side logic and databases

×

Backend Development

Description: Backend developers handle the server-side logic, databases, and APIs that power web applications and ensure data flows correctly between front and back ends.

Recommended Education: Bachelor’s in Computer Science, Software Engineering, or self-taught with backend project experience.

Key Skills:

  • Node.js, Python, Java, Ruby, or PHP
  • Databases: SQL & NoSQL
  • RESTful APIs & GraphQL
  • Authentication & Authorization
  • Cloud & Server Management

Common Roles: Backend Engineer, API Developer, Database Developer, Systems Architect.

Good For: Problem-solvers who enjoy building logical systems behind the scenes and managing data.

Step by Step Backend Development Roadmap

Full Stack Development

Work on both frontend and backend to create complete applications

×

Full Stack Development

Description: Full Stack Developers work on both frontend and backend, creating complete web applications, bridging design and server-side logic.

Recommended Education: Bachelor’s in Computer Science, bootcamps covering full stack, or self-taught with projects demonstrating both frontend and backend skills.

Key Skills:

  • Frontend: HTML/CSS/JS, React/Vue/Angular
  • Backend: Node.js, Python, Java, Ruby
  • Databases & API design
  • Version Control (Git)
  • Deployment & Cloud

Common Roles: Full Stack Developer, Web Developer, Application Engineer.

Good For: Developers who like working on all aspects of a project, from UI to server infrastructure.

Step by Step Full Stack Development Roadmap

Mobile Development

Create apps for iOS and Android devices

×

Mobile Development

Description: Mobile developers create applications for iOS and Android, optimizing for device performance, touch interactions, and platform guidelines.

Recommended Education: CS degree, mobile app bootcamps, or self-taught with portfolio.

Key Skills:

  • Swift (iOS) / Kotlin (Android)
  • React Native / Flutter
  • UI/UX for mobile
  • APIs & data management
  • Testing & debugging on multiple devices

Common Roles: iOS Developer, Android Developer, Cross-platform Developer.

Good For: Developers who love building apps for users to interact with on their phones and tablets.

AI Prompt Engineering

Data Science & Analytics

Extract insights from data to drive decisions

×

Data Science & Analytics

Description: Data Scientists analyze and interpret data to provide actionable insights, often building predictive models and dashboards.

Recommended Education: CS, Statistics, Data Science degrees; bootcamps or self-taught projects.

Key Skills:

  • Data Visualization (Tableau, PowerBI)
  • Machine Learning & Statistics
  • Data Cleaning & ETL

Data Engineering

Build pipelines and infrastructure to manage data

×

Data Engineering

Description: Data Engineers build and maintain pipelines, ensuring that data is stored, processed, and available for analysis efficiently and reliably.

Recommended Education: CS or Data Engineering degrees, or self-taught with ETL projects.

Key Skills:

  • ETL Tools (Airflow, dbt)

Common Roles: Data Engineer, ETL Developer, Big Data Engineer.

Infrastructure & Systems

Careers that keep systems running reliably, manage cloud platforms, and secure data and applications.

Cloud Computing

Build and manage scalable cloud infrastructure

×

Cloud Computing

Description: Cloud engineers design, deploy, and maintain cloud infrastructure, ensuring scalability, security, and reliability for applications and services.

Recommended Education: Bachelor’s in Computer Science, Information Systems, Cloud Certifications (AWS, Azure, GCP)

Key Skills:

  • Cloud Platforms (AWS, Azure, GCP)
  • Networking & Security
  • Infrastructure as Code (Terraform, CloudFormation)
  • Linux & Windows Server Administration
  • Containerization (Docker, Kubernetes)
  • Monitoring & Optimization

Common Roles: Cloud Engineer, Cloud Architect, DevOps Engineer, Site Reliability Engineer

Good For: Problem-solvers who enjoy managing infrastructure, automating systems, and optimizing cloud-based solutions.

DevOps & SRE

Automate and optimize software delivery

×

DevOps & Site Reliability Engineering (SRE)

Description: DevOps and SRE professionals streamline software development and operations, focusing on automation, CI/CD, reliability, and system scalability.

Recommended Education: Bachelor’s in CS or related field, DevOps courses/certifications

Key Skills:

  • CI/CD Tools (Jenkins, GitHub Actions, GitLab)
  • Containerization & Orchestration (Docker, Kubernetes)
  • Monitoring & Logging (Prometheus, Grafana, ELK)
  • Cloud Platforms (AWS, Azure, GCP)
  • Scripting (Python, Bash, PowerShell)
  • Collaboration & Agile Practices

Common Roles: DevOps Engineer, Site Reliability Engineer, Platform Engineer

Good For: Those who love building automation, improving workflows, and ensuring systems are stable and scalable.

Cyber Security

Protect systems, networks, and data from cyber threats

×

Cyber Security

Description: Cybersecurity professionals protect networks, systems, and data from attacks, vulnerabilities, and unauthorized access, ensuring digital safety. They identify vulnerabilities, implement security measures, and respond to incidents.

Recommended Education: Bachelor’s in CS, Cybersecurity, or InfoSec certifications (CompTIA Security+, CEH, CISSP)

Key Skills:

  • Network Security & Firewalls
  • Penetration Testing & Ethical Hacking
  • Threat Analysis & Incident Response
  • Cryptography & Secure Coding
  • Compliance & Risk Management

Common Roles: Security Analyst, Penetration Tester, Security Engineer, Security Consultant

Good For: Detail-oriented individuals who enjoy protecting digital assets and analyzing potential threats.

Step by Step Cybersecurity Roadmap

Platform Engineering

Build internal tools and systems to support other developers

×

Platform Engineering

Description: Platform engineers build internal systems, tools, and frameworks that support development teams, improving productivity and reliability.

Recommended Education: Bachelor’s in CS or related field, DevOps and Cloud experience

Key Skills:

  • Cloud Infrastructure (AWS, GCP, Azure)
  • Automation & Scripting (Python, Bash)
  • CI/CD & Pipelines
  • Monitoring & Observability Tools
  • Collaboration & System Design

Common Roles: Platform Engineer, Developer Experience Engineer, Infrastructure Engineer

Good For: Problem-solvers who enjoy building scalable developer tools and improving team workflows.

Emerging Technology

New and future-focused tech fields shaping the digital world.

Robotics Engineering

Develop intelligent machines and automation systems

×

Robotics Engineering

Description: Robotics engineers design, build, and maintain intelligent machines and automated systems for manufacturing, healthcare, research, and consumer applications.

Recommended Education: Bachelor’s or Master’s in Robotics, Mechanical Engineering, Electrical Engineering, or Mechatronics.

Key Skills:

  • Mechanical design and CAD
  • Control systems and sensors
  • Embedded programming (C/C++, Python)
  • Robotics frameworks (ROS)
  • AI and Machine Learning basics

Common Roles: Robotics Engineer, Automation Engineer, Mechatronics Engineer.

Good For: Problem-solvers and tinkerers who love building physical systems and integrating hardware with software.

Embedded Systems & IoT

Create software for smart, connected devices

×

Embedded Systems & IoT

Description: Embedded systems engineers develop software for devices with dedicated functions, often connected to the internet, such as smart appliances, sensors, and industrial machines.

Recommended Education: Bachelor’s in Electrical Engineering, Computer Engineering, or IoT/Embedded Systems programs.

Key Skills:

  • Microcontrollers (Arduino, STM32, ESP32)
  • Embedded C/C++ programming
  • IoT protocols (MQTT, CoAP)
  • Sensor integration and data collection
  • Basic electronics and circuit design

Common Roles: Embedded Systems Engineer, IoT Developer, Firmware Engineer.

Good For: Engineers who enjoy low-level programming, electronics, and connecting devices to smart systems.

AR / VR Development

Build immersive augmented and virtual experiences

×

AR / VR Development

Description: AR/VR developers create immersive digital experiences using augmented reality (AR) and virtual reality (VR) technologies for games, training, simulations, and interactive media.

Recommended Education: Bachelor’s in Computer Science, Game Design, or Interactive Media; AR/VR Bootcamps.

Key Skills:

  • Unity or Unreal Engine
  • C#, C++
  • 3D modeling and animation basics
  • AR/VR device SDKs (Oculus, HoloLens, ARKit/ARCore)
  • UX for immersive experiences

Common Roles: AR Developer, VR Developer, Immersive Experience Designer.

Good For: Creatives and developers passionate about storytelling, interactivity, and 3D environments.

Blockchain & Web3

Develop decentralized and blockchain-based applications

×

Blockchain & Web3

Description: Blockchain and Web3 developers build decentralized applications, smart contracts, and infrastructure for cryptocurrencies, NFTs, and distributed systems.

Recommended Education: Bachelor’s in Computer Science, Blockchain Bootcamps, or self-taught with projects.

Key Skills:

  • Solidity or smart contract languages
  • Ethereum, Polygon, or other blockchain platforms
  • Web3.js / Ethers.js
  • Cryptography basics
  • Decentralized application (dApp) development

Common Roles: Blockchain Developer, Smart Contract Engineer, Web3 Developer.

Good For: Developers excited about decentralization, finance, and building new digital ecosystems.

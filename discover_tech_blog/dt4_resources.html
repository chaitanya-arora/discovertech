Learning Platforms

Platforms that provide structured courses, tutorials, and guided learning paths to help beginners start programming and build real-world projects.

The Odin Project

Free, open-source full-stack web development curriculum focusing on building real projects using HTML, CSS, JavaScript, Git, and Node.js.

Personal Favourite Free Project-based Web Dev Community

Codédex

Gamified coding learning platform that turns programming into an adventure-style experience. Users earn XP, unlock regions, and learn languages like Python, HTML, CSS, and JavaScript through interactive lessons and challenges.

Personal Favourite Gamified Beginner Friendly Interactive Lessons Projects

freeCodeCamp

One of the largest free coding platforms with thousands of lessons, coding challenges, and certifications. Covers web development, data science, Python, machine learning, and more with project-based learning.

Free Beginner Friendly Project-based Certifications

Codecademy

Interactive coding platform offering courses in Python, JavaScript, C++, SQL, and more. Includes exercises and guided projects with a freemium model.

Interactive Beginner Friendly Freemium Multiple Languages

CS50 (Harvard)

One of the most popular introductory computer science courses online, teaching programming fundamentals, algorithms, and problem solving through real projects.

Free University Course Computer Science Beginner

Coursera

Online learning platform offering courses, certificates, and full specializations from universities and tech companies such as Google, Meta, and Stanford. Covers programming, computer science, AI, and data science.

University Courses Certificates Career Paths Freemium

Kaggle

Data science and machine learning platform offering datasets, competitions, notebooks, and free micro-courses for learning Python, data analysis, and machine learning.

AI/ML Datasets Competitions Hands-on Learning

Documentation/Learning References

Guides, documentation, and reference sites that explain programming concepts, syntax, and best practices.


roadmap.sh

Visual roadmaps showing the skills needed for roles like frontend developer, backend developer, DevOps engineer, and more.

Personal Favourite Career Paths Visual Roadmaps Self-guided Learning

W3Schools

A popular educational website offering beginner tutorials and references for web development technologies like HTML, CSS, JavaScript, Python, and SQL with an in-browser code editor.

Personal Favourite Beginner Friendly Reference Web Dev Interactive Editor

GeeksforGeeks

Large programming resource with tutorials, interview prep, data structures explanations, and coding problems widely used by students preparing for technical interviews.

Personal Favourite Tutorials Interview Prep DSA Articles

MDN Web Docs

Highly trusted documentation for web technologies including HTML, CSS, JavaScript, and browser APIs maintained by Mozilla.

Documentation Web Dev Reference

YouTube Channels

YouTube creators who teach programming through tutorials, project walkthroughs, and full coding courses.


Bro Code

Beginner-friendly programming tutorials covering Python, Java, JavaScript, and game development with step-by-step explanations.

Personal Favourite Beginner Tutorials Multiple Languages

Programming with Mosh

Clear and practical tutorials on programming languages like Python, JavaScript, and C#. Known for beginner-friendly explanations and structured lessons.

Personal Favourite Beginner Friendly Structured Lessons Software Engineering

Coder Coder

Frontend development tutorials focusing on HTML, CSS, JavaScript, and responsive web design with beginner-friendly explanations and practical projects.

Personal Favourite Web Dev Frontend Projects Beginner Friendly

freeCodeCamp (YouTube)

Massive collection of full-length programming tutorials covering Python, web development, data science, and more. Many videos are complete courses several hours long.

Free Full Courses Beginner Friendly

Traversy Media

Highly respected web development channel offering crash courses and full projects on modern technologies like React, Node.js, and MongoDB.

Web Dev Projects Crash Courses

Net Ninja

Structured playlists covering topics like JavaScript, React, Firebase, and Node.js with clear step-by-step tutorials.

Structured Playlists Web Dev Beginner Friendly

Platforms for practicing algorithms, solving coding challenges, and preparing for technical interviews.


LeetCode

Popular coding practice platform with algorithm problems used in technical interviews at companies like Google, Amazon, and Meta.

Personal Favourite DSA Practice Interview Prep Competitive Coding

NeetCode

Popular interview preparation platform that organizes LeetCode problems into structured roadmaps like the famous NeetCode 150, with explanations and video solutions.

HackerRank

Coding challenge platform with practice problems in algorithms, databases, AI, and cybersecurity plus company-sponsored coding challenges.

Practice Problems Competitions Skill Certification
